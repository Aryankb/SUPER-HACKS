[Sigmoyd Whatsapp](https://www.sigmoyd.in/whatsapp) - Your personal AI assistant on whatsapp which can set reminders, remember notes/documents, and interact with Gmail, Google Sheets, Notion, Trello, etc. (15+ Integrations)


[Sigmoyd Workflow](https://www.sigmoyd.in) - Create Agentic workflows (just like n8n) from prompts and activate on single click.  Engineered an scalable AI infrastructure - a no-code platform for generating autonomous AI agentic workflows via
 natural language prompts. These workflows can be triggered by WhatsApp msg, mail arrivals, etc. (5+ Triggers)
